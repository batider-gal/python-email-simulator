# Python Email Simulator

A simple email simulator built with Python using object-oriented programming.

## Features

- Create users with individual inboxes
- Send emails between users
- View received emails
- Mark emails as read
- Delete emails
- Track the date and time an email was received

## Concepts Used

- Python classes and objects
- `__init__` and `self`
- Attributes and methods
- Lists
- Object interaction
- Magic methods (`__str__`)
- `datetime`

## How to Run

Run the program with Python:

python email_simulator.py
